Diagram 1 — Room

where the two cables go

The Sight sits mid-table and needs exactly two cables: a short power jumper to the PoE+ injector at the table, and one data run across the room to a small host dongle that plugs straight into the Rally Bar. The Sight never touches the Tap, the network, or yesterday's TV chain.

If the run uses the A07 wall plate, the whole path plate-to-bar must still be shielded Cat6A with no switch in between — it carries USB, not Ethernet.

Diagram 2 — Connections

every jack · every rule

The Sight base has three RJ45 jacks but they are not Ethernet: POWER takes PoE+ from the injector, DATA is a Logitech USB-over-Cat link to the host dongle at the bar, and MIC POD is only for optional mic pods. Power and data never share a cable.

The Hookup

in order · no pairing step exists
  1. Power first. Wall outlet → Phihong injector → Sight POWER jack (short jumper at the table). Injector LED: solid green = powering · slow amber blink = not seeing the Sight (check the far end) · fast amber blink = short, unplug. If the Phihong is feeding the Tap today, the Tap needs its own power — its OEM DC brick (check the boxes) or any 802.3af injector; the bar's USB-C will not power a Tap. One injector never feeds two.
  2. The run. Sight DATA jack → shielded Cat6A → host dongle at the bar. No Cat6A ships in the Sight kit — the run is your own cable, and the kit's Tap Cat5e cable is the wrong spec (don't substitute it). Shielded by eye: "S/FTP" printed on the jacket + metal RJ45 shell (plastic plug = UTP = won't work). Passive path only — using the A07 plate? Test it with a laptop first: link light / DHCP = live switch port, don't use it; dead = good.
  3. The dongle. Plug its two short leads straight into the bar: USB-A + MIC POD ports. No USB hubs.
  4. Watch it boot. LED loops blue → lilac → white → cyan, then solid cyan = ready. The real go/no-go: it appears under Settings › Peripherals on the bar. Cyan but not listed = see the rescue list at the bottom — on 2.0.x firmware that's a known bug, not your wiring.
  5. Turn it on as a camera. Settings › Camera › RightSight 2 › Speaker View. Auto hand-off needs CollabOS 1.13+ — on by default since 2.0.A; current is 2.1.0, which also fixes Sight-detection bugs. Behind on firmware? Update on-device: Settings › Updates › Update (~20 min, no Teams admin needed).
  6. Admin PIN reality. Teams mode has no factory default PIN — if none was ever set, it prompts you to create one on the spot. If a PIN bounces you, one was set by the installer or pushed from Teams admin (1234 is only the non-Teams default).
  7. Prove it. Live test call — talk from different seats, watch the camera hand off between bar and Sight. Then log the serial off the base label.
From the base label: Sight model VU0067 · PoE, ~14W draw, needs PoE+ (at) class supply.
Verify onsite: A07 run shielded + passive (laptop test) · what the Phihong feeds today · CollabOS ≥ 1.13 · a real Cat6A S/FTP cable on the truck — the kit doesn't include one.
Not involved: the Tap · the LAN · yesterday's TV/HDMI chain.

If It Won't Show Up

rescue list · most likely first
  1. Cyan but not in Peripherals? Firmware first, cables second — every 2.0.x build has a documented bug matching this exact symptom, fixed in 2.1.0 (Settings › Updates). Already on 2.1+? Reseat the DATA cable at both ends and the dongle's two leads → power-cycle the Sight (pull the injector-side plug 30 s — it has no power button) → reboot the bar → try one of the other USB-A ports (any of the 3 is valid).
  2. LED loops forever, never settles cyan? Confirm the injector shows solid green, power-cycle once, then factory reset (below). Still looping = dead unit — 2-year warranty, stop burning time on it.
  3. No LED, injector green? The run is the suspect: not truly S/FTP end-to-end, over 20 m, or a bad jack. Swap in a known-good shielded cable before blaming the Sight.
  4. Lilac pulse? It's updating — hands off. No documented duration; only if it's clearly stuck well past ~15 min, power-cycle and let it retry.
  5. Sight factory reset: hold Reset + one mic-mute button for 10 s (no pinhole, no beep). It then sits dark for up to 5 minutes before rebooting — that's normal, don't panic-unplug.

Hard datasheet limit: 20 m dongle-to-Sight, no exceptions — if you see a 40 m figure anywhere, it's wrong.
