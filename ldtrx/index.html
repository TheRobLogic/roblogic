Progression
  • Strap angle is the primary lever. Pulls: walk feet toward the anchor (steeper body angle = harder). Feet on a box positioned under the anchor is the hardest variation. Pushes: walk feet farther from anchor or elevate them. Do not progress pulls by elevating feet on a wall away from the anchor — that reduces lever and is regression, not progression.
  • Tempo before reps. Add :1 to the eccentric before adding reps. So 3-0-1-0 → 4-0-1-0 → 4-1-1-0 over 3 weeks before bumping reps.
  • Volume rules. Start at the lower bound of prescribed sets. Add a set when all reps hit at RPE ≤ 7. Cap at +1 set per block per 3 weeks.
  • RPE / RIR. Mains run RPE 7–8 (2–3 RIR). Finishers run RPE 7–8 on iso quality, not breathing. If finishers turn into a metcon, regress strap angle.
  • Session B tempo is non-negotiable. 3-1-3-0 on Session B mains is the control-bias. Slow is the stimulus — if it gets easy, progress strap angle, not tempo.
  • Variety axis rotation. Hold a base template for 2 weeks, then swap one slot to an alt for 2 weeks. After ~6 weeks, audit progression markers and reset the base with the alts you've improved on most.
Weekly Placement
  • 48 hr minimum between A and B. Never back-to-back.
  • Mix the order however fits your week — A first, B first, doesn't matter.
Skip / Scale Rules
  • Beat up? Drop the finisher, drop one set off A1/A2, keep the warm-up + main work.
  • Smoked? Skip. It can wait.
  • Feeling good? Add a set, drop rest, slow the tempo down further.
