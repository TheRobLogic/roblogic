what

grip-inventory

A small app you run on a computer at your house that tracks your gear. You talk to it. It writes things down. Nobody else sees it.

what it does

The first time, you walk your kit and tell the app what you have, snapping photos as you go. After that, you just talk to it like a person. "Marco took the C-stand kit to truck B." The app understands the sentence and updates your list. It pings your phone when something you loaned out has been gone too long. You reach it from set through a private connection — it never sits on the public internet.

the parts

  • a code editor with AI built in (Cursor or Claude Code) — the tool you use to build the app
  • Python — the language the AI writes the app in, you mostly read it
  • a simple web server framework called FastAPI — one file, easy to follow
  • a small database file (SQLite) — your data lives here; copy the file to back it up
  • a web page that installs on your iPhone like a real app
  • an AI "brain" (Claude) — turns your sentences into updates to the list
  • a free push notification service (ntfy.sh) — for the reminder pings
  • a private network tool (Tailscale) — lets your phone reach the home computer from anywhere
  • GitHub — where the source code is kept; open so others can use it too
  • an always-on computer at your house — whatever you've got, even an old laptop

how it gets built

  1. install the editor, make a GitHub account, get an API key from Anthropic
  2. ask the AI to write the basic skeleton — a list of items, a place to add new ones
  3. type in your own gear and your slang ("stinger" is a particular cable, etc.)
  4. wire up the part that reads your sentences and changes the list
  5. add the reminders for loans
  6. move the whole thing to your home computer and set up the private network
  7. use it on a job, see what breaks, ask the AI to fix it

what it costs each month

editorfree, or $20
AI brainabout 7 cents
github, tailscale, ntfyfree
home computerwhatever you have
all-in monthlyunder $25

about the code

The code lives in a public folder on GitHub under an open license — anyone can read it, fork it, use it. Rob has access too, so he can help when you're stuck. Your actual gear list never goes in the code; it stays on your computer.

grip-inventory

It's a magic notebook. You talk to it. It writes things down for you. It lives in your house.

what it does

You point at every piece of gear once and tell the notebook what it is. The notebook listens. After that, you just say things like "Marco took the dolly" and it remembers. When you ask "where's the dolly?" it tells you. When Marco still has the dolly three days later, the notebook taps your phone on the shoulder: "hey, Marco still has the dolly."

the parts (don't sweat the names)

  • a robot helper that writes computer code for you — you tell it what you want, it types the code
  • a box that runs the notebook — a computer at your house, always on
  • a secret tunnel so your phone can talk to the box from anywhere (Tailscale)
  • a brain inside the notebook that understands sentences (we rent it for pennies)
  • a bell that rings on your phone when something needs your attention

how you build it

  1. get the robot helper installed on your computer
  2. tell it: "make me a notebook with pages for my stuff" — it writes the code
  3. write down all your gear in the notebook
  4. hook up the brain so it understands what you say
  5. hook up the bell
  6. move the whole thing to the box at your house and open the secret tunnel
  7. try it on a job — when something is dumb, tell the robot helper to fix it

money

A few bucks a month. Less than coffee. Most of the parts are free.

the recipe

The recipe for the notebook lives on the internet for anyone to read. Rob can read along too and help when you're stuck. The stuff inside the notebook — your gear — only you can see. That part stays in your house.

Self-hosted natural-language gear tracker for a working key grip. Built solo, run solo. Not a SaaS, not for sale.

value

Build. Solo PoC, friend owns and hosts. Two open calls: pick code editor (Cursor or Claude Code) and confirm home-box hardware. Everything else is settled.
